The one line a smart fridge texts its owner at 3am — a machine that has
been awake all night, humming in the dark, finally deciding this is the
moment to speak:

> 3am. You ate the last slice standing in the dark. I am a fridge. I keep things cold — and I keep receipts.

106 characters — inside the 140-character cap.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
